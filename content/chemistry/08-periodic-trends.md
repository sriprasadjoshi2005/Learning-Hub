---
title: Periodic Trends
level: foundation
---

Properties of elements repeat in a pattern because the outer electron arrangements repeat. Two ideas explain almost every trend: **effective nuclear charge** ($Z_{\text{eff}}$, the pull the outer electrons actually feel after inner electrons shield part of the nuclear charge) and **distance** from the nucleus.

- Across a period, $Z_{\text{eff}}$ rises while the shell stays the same, so atoms shrink and hold their electrons more tightly.
- Down a group, new shells are added, so atoms grow and outer electrons are held more loosely.

## Atomic and ionic radius

Radius decreases left to right and increases down a group. A cation is smaller than its atom (fewer electrons, same nucleus), and an anion is larger. Among **isoelectronic** species (same number of electrons), the one with the larger nuclear charge is smaller: $\mathrm{O^{2-}} > \mathrm{F^-} > \mathrm{Na^+} > \mathrm{Mg^{2+}} > \mathrm{Al^{3+}}$.

## Ionisation enthalpy

First ionisation enthalpy generally increases across a period, but there are two classic dips:

- **Be to B:** boron's outer electron is in a $2p$ orbital, which is higher in energy and easier to remove than beryllium's $2s$ electron, so $\mathrm{B} < \mathrm{Be}$.
- **N to O:** oxygen's fourth $2p$ electron must pair with another in the same orbital, and the repulsion makes it easier to remove, so $\mathrm{O} < \mathrm{N}$ (nitrogen has a stable half-filled $2p^3$).

For the second period the values (kJ mol$^{-1}$) are Li 520, Be 899, B 801, C 1086, N 1402, O 1314, F 1681, Ne 2081.

## Electron gain enthalpy and electronegativity

Electron gain enthalpy is the energy change when an atom gains an electron; more negative means a greater tendency to gain. It generally becomes more negative across a period. The exception that exams love: **chlorine is more negative than fluorine**, because fluorine's very small $2p$ subshell makes the incoming electron suffer strong repulsion from the electrons already there.

Electronegativity (Pauling scale) increases across a period and decreases down a group, with fluorine the highest at $4.0$.

## Quiz

1. Which of the following correctly lists the ions in increasing order of radius?
   - [ ] $\mathrm{F^-} < \mathrm{Na^+} < \mathrm{Mg^{2+}} < \mathrm{Al^{3+}}$
   - [x] $\mathrm{Al^{3+}} < \mathrm{Mg^{2+}} < \mathrm{Na^+} < \mathrm{F^-}$
   - [ ] $\mathrm{Na^+} < \mathrm{Al^{3+}} < \mathrm{Mg^{2+}} < \mathrm{F^-}$
   - [ ] $\mathrm{Mg^{2+}} < \mathrm{Al^{3+}} < \mathrm{F^-} < \mathrm{Na^+}$
   > All four have 10 electrons, so the one with the most protons pulls hardest and is smallest: $\mathrm{Al^{3+}}$ (13 protons) is smallest and $\mathrm{F^-}$ (9 protons) is largest.

2. Which sequence correctly arranges B, Be, C, N and O in increasing order of first ionisation enthalpy?
   - [x] B < Be < C < O < N
   - [ ] Be < B < C < N < O
   - [ ] B < Be < C < N < O
   - [ ] Be < B < C < O < N
   > Values are B 801, Be 899, C 1086, O 1314, N 1402 kJ mol$^{-1}$. Two irregularities break the smooth rise: B is below Be, and O is below N.

3. Which element has the most negative electron gain enthalpy?
   - [ ] F
   - [ ] Br
   - [ ] I
   - [x] Cl
   > Chlorine ($-349$ kJ mol$^{-1}$) is more negative than fluorine ($-328$). Fluorine's compact $2p$ subshell causes strong electron-electron repulsion for the incoming electron. After chlorine, the values fall in magnitude down the group.
