# Lesson 36: Applications of Derivatives: Monotonicity and Extrema

## Learning objective

Use first and second derivatives to locate increasing/decreasing intervals, local extrema and optimisation solutions.

## Core concepts

- If f'(x)>0 throughout an interval, f is increasing there; if f'(x)<0, it is decreasing.
- Critical points occur where f'(x)=0 or f' is undefined, provided the function itself is defined there.
- First derivative test: a sign change from + to − indicates a local maximum; − to + indicates a local minimum.
- Second derivative test: if f'(a)=0 and f''(a)>0, there is a local minimum; if f''(a)<0, a local maximum. If f''(a)=0, the test is inconclusive.
- For absolute extrema on a closed interval, compare function values at critical points and both endpoints.

## Essential formulae and results

f'>0 increasing; f'<0 decreasing; f'=0 candidates for extrema.

## Worked examples

**Example 1.** For f(x)=x²−4x+1, f'=2x−4=0 at x=2 and f''=2>0, so a minimum occurs; f(2)=−3.
**Example 2.** For f(x)=x³−3x, f'=3(x²−1), so critical points are −1 and 1; use the sign of f' on the intervals to classify them.

## Common mistakes to avoid

- A stationary point is not automatically a maximum or minimum.
- The second derivative test can be inconclusive.
- For a closed interval, endpoints can be absolute extrema even when f' is not zero.

## Quick quiz

**1. If f' changes from positive to negative, the point is a:**
- [ ] Local minimum
- [x] Local maximum
- [ ] Point of inflection always
- [ ] Discontinuity
> **Explanation:** The function changes from increasing to decreasing.

**2. For f(x)=x², the critical point x=0 is a:**
- [ ] Maximum
- [x] Minimum
- [ ] Neither
- [ ] Undefined point
> **Explanation:** f''(0)=2>0, so it is a minimum.

**3. To find absolute extrema on [a,b], compare:**
- [ ] Only f'(a) and f'(b)
- [ ] Only stationary points
- [x] Critical-point values and endpoint values
- [ ] Only second derivatives
> **Explanation:** All candidates in the closed interval must be checked.
