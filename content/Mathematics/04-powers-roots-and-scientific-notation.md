# Lesson 4: Powers, Roots and Scientific Notation

## Learning objective

Develop fluency with exponents, radicals and scientific notation, which are used throughout algebra, geometry and science.

## Core concepts

- For non-zero a, a^m × a^n = a^(m+n), a^m/a^n = a^(m−n), and (a^m)^n = a^(mn).
- For a ≠ 0, a^0 = 1 and a^(−n) = 1/a^n. For suitable real values, a^(1/n) is the nth root of a.
- Simplify radicals by extracting perfect-power factors: √72 = √(36 × 2) = 6√2.
- Scientific notation writes a number as c × 10^n, where 1 ≤ |c| < 10. It is useful for very large and very small values.
- For real-number work, an even root requires a non-negative radicand. Always check the domain before simplifying.

## Essential formulae and results

a^m a^n=a^(m+n); a^m/a^n=a^(m−n); (a^m)^n=a^(mn); a^(−n)=1/a^n.

## Worked examples

**Example 1.** Simplify 2^3 × 2^−5 = 2^(3−5) = 2^−2 = 1/4.
**Example 2.** Write 0.000072 in scientific notation: move the decimal five places right to obtain 7.2, so the number is 7.2 × 10^−5.

## Common mistakes to avoid

- The rule (a+b)^2 = a^2+b^2 is false; the middle term is 2ab.
- A negative exponent means reciprocal, not a negative value.
- √(a²) = |a| for real a, not always a.

## Quick quiz

**1. Simplify 3² × 3^4.**
- [ ] 3^8
- [x] 3^6
- [ ] 3^2
- [ ] 9^4
> **Explanation:** Add exponents with the same non-zero base: 3^(2+4) = 3^6.

**2. Evaluate 5^0.**
- [ ] 0
- [ ] 5
- [x] 1
- [ ] −1
> **Explanation:** Any non-zero number raised to zero is 1.

**3. Simplify √50.**
- [ ] 25√2
- [x] 5√2
- [ ] 10√5
- [ ] 2√5
> **Explanation:** √50 = √(25 × 2) = 5√2.
