## Learning objective

Learn the language of sets, subsets, unions, intersections and complements. Set notation is essential for functions, probability and mathematical reasoning.

## Core concepts

- A set is a well-defined collection. x ∈ A means x is an element; x ∉ A means it is not.
- A ⊆ B means every element of A is in B. The empty set ∅ is a subset of every set.
- A ∪ B contains elements in A or B or both; A ∩ B contains elements common to both. A\B contains elements in A but not B.
- The complement A' consists of elements in the universal set U that are not in A.
- An interval (a,b) excludes endpoints; [a,b] includes both; [a,b) includes a but excludes b. Infinite endpoints always use parentheses.
- De Morgan's laws: (A ∪ B)' = A' ∩ B' and (A ∩ B)' = A' ∪ B'.

## Essential formulae and results

n(A∪B)=n(A)+n(B)−n(A∩B).

## Worked examples

**Example 1.** Let A={1,2,3} and B={3,4}. Then A∪B={1,2,3,4}, A∩B={3}, and A\B={1,2}.
**Example 2.** The inequality −2 ≤ x < 5 is the interval [−2,5).

## Common mistakes to avoid

- The union is not the same as the intersection.
- A set with no elements is ∅; {∅} is a set containing one element.
- Check whether interval endpoints are included.

## Exam approach

1. Identify the topic and write down the relevant definition or formula.
2. Check the conditions: domain, non-zero denominators, interval, sign and units where applicable.
3. Show the essential algebraic steps instead of jumping to an answer.
4. Substitute the result into the original condition whenever extraneous solutions are possible.
5. Keep exact values (fractions, radicals and π) until a decimal approximation is requested.

## Quiz

1. If A={1,2,3} and B={2,3,4}, then A∩B is:
- [ ] {1,4}
- [x] {2,3}
- [ ] {1,2,3,4}
- [ ] ∅
> The intersection contains only common elements.

2. The interval x > 4 is:
- [ ] [4,∞)
- [x] (4,∞)
- [ ] (−∞,4)
- [ ] (4,∞]
> Four is excluded, so use a parenthesis.

3. If U={1,2,3,4} and A={1,3}, A' is:
- [ ] {1,3}
- [x] {2,4}
- [ ] {1,2,3,4}
- [ ] ∅
> The complement contains elements of U not in A.
