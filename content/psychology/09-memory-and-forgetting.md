# Lesson 9: Memory and Forgetting

Memory is the psychological process through which information is encoded, stored and retrieved. It allows individuals to retain knowledge, recognise familiar experiences, develop skills and use previous experiences to guide future behaviour.

## 1. Meaning of Memory

Memory refers to the processes involved in acquiring, retaining and retrieving information over time.

Examples include:

- Remembering a person's name.
- Recalling historical events.
- Recognising a familiar location.
- Remembering mathematical formulas.
- Recalling personal experiences.

Memory is not a perfect recording of the past. It is a constructive process that can be influenced by attention, emotion, expectations and later information.

## 2. Three Basic Processes of Memory

### 2.1 Encoding

Encoding is the process of converting information into a form that can be stored.

Examples include:

- Understanding the meaning of a concept.
- Associating a new word with an image.
- Repeating information.
- Organising information into categories.

### 2.2 Storage

Storage refers to retaining encoded information over time.

### 2.3 Retrieval

Retrieval is the process of accessing stored information when needed.

Examples include recalling an answer during an examination or recognising a familiar face.

## 3. The Information Processing Model

Memory is often explained through a model involving sensory memory, short-term memory and long-term memory.

<AsyncImage query="Atkinson Shiffrin modal model sensory memory short term memory long term memory arrows rehearsal educational psychology diagram" aspectRatio="16:9" width="100%" />

### 3.1 Sensory Memory

Sensory memory briefly retains information received through the senses.

It has a very short duration and large initial capacity.

Types include:

**Iconic memory:** Brief visual memory.

**Echoic memory:** Brief auditory memory.

Sensory memory allows information to remain available briefly for further processing.

### 3.2 Short-Term Memory

Short-term memory temporarily holds a limited amount of information.

Its duration is generally brief without rehearsal.

Example: Remembering a phone number long enough to dial it.

### 3.3 Long-Term Memory

Long-term memory stores information over extended periods.

Its capacity is considered extremely large, although retrieval may not always be accurate or successful.

Examples include:

- Vocabulary.
- Personal experiences.
- Learned facts.
- Motor skills.

## 4. Working Memory

Working memory is a system responsible for temporarily maintaining and manipulating information during ongoing cognitive activities.

It is associated with the work of Alan Baddeley and Graham Hitch.

### 4.1 Components of Working Memory

**Central executive:** Directs attention and coordinates information processing.

**Phonological loop:** Maintains and processes speech-based or sound-related information.

**Visuospatial sketchpad:** Maintains and manipulates visual and spatial information.

**Episodic buffer:** Integrates information from different sources into coherent representations.

Example:

Solving a mathematical problem mentally requires temporarily holding numbers, intermediate results and instructions while manipulating them.

## 5. Types of Long-Term Memory

Long-term memory can be divided into explicit and implicit memory.

<AsyncImage query="long term memory classification explicit declarative episodic semantic implicit procedural priming conditioning psychology chart" aspectRatio="16:9" width="100%" />

### 5.1 Explicit Memory

Explicit memory, also called declarative memory, involves conscious recollection.

It includes:

**Episodic memory:** Memory of personal experiences and events.

Example: Remembering a birthday celebration.

**Semantic memory:** Memory of facts, concepts and general knowledge.

Example: Knowing that water has the chemical formula H₂O.

### 5.2 Implicit Memory

Implicit memory influences behaviour without requiring conscious recollection.

It includes:

**Procedural memory:** Memory of skills and actions.

Example: Riding a bicycle.

**Priming:** Previous exposure to information influences later responses.

**Conditioning:** Learned associations influence responses.

## 6. Encoding and Improving Memory

Information can be encoded in different ways.

### 6.1 Visual Encoding

Information is represented through images, diagrams and visual patterns.

### 6.2 Acoustic Encoding

Information is encoded through sound or pronunciation.

### 6.3 Semantic Encoding

Information is encoded according to meaning.

Semantic encoding is often especially useful for retaining meaningful information.

### 6.4 Organisation

Grouping related information into meaningful categories can improve recall.

### 6.5 Chunking

Chunking involves grouping smaller pieces of information into larger meaningful units.

Example:

The sequence 1-9-4-7-2-0-2-6 may be easier to remember when organised into meaningful groups.

### 6.6 Elaborative Rehearsal

Elaborative rehearsal involves connecting new information with existing knowledge and understanding its meaning.

It generally supports long-term retention more effectively than simple repetition alone.

## 7. Retrieval and Retrieval Cues

Retrieval cues are pieces of information that help access stored memories.

Examples include:

- A familiar smell.
- A photograph.
- A particular location.
- A related word.
- A previous question.

### 7.1 Recall

Recall involves retrieving information without being directly presented with the answer.

Example: Writing a definition from memory.

### 7.2 Recognition

Recognition involves identifying previously encountered information.

Example: Selecting a correct answer from multiple-choice options.

### 7.3 Relearning

Relearning involves acquiring previously learned information again.

Information that was learned earlier may require less effort to learn again.

## 8. Forgetting

Forgetting is the inability to retrieve or retain previously learned information.

It can occur for several reasons.

### 8.1 Decay Theory

The decay explanation proposes that memory traces may weaken over time when they are not used.

### 8.2 Interference Theory

Interference occurs when competing information makes retrieval difficult.

Two major types are:

**Proactive interference:** Older information interferes with learning or recalling newer information.

Example: An old password makes it difficult to remember a newly created password.

**Retroactive interference:** Newer information interferes with recalling older information.

Example: A newly learned phone number makes an older number harder to recall.

### 8.3 Retrieval Failure

Information may be stored but temporarily inaccessible because appropriate retrieval cues are missing.

### 8.4 Encoding Failure

Information that was never properly encoded may not be available for later retrieval.

### 8.5 Motivated Forgetting

Some psychological theories propose that individuals may avoid recalling distressing information.

However, the mechanisms and extent of motivated forgetting are complex and should not be assumed to explain every memory failure.

## 9. Ebbinghaus and the Forgetting Curve

Hermann Ebbinghaus investigated memory through experiments involving lists of meaningless syllables.

He demonstrated that forgetting can occur rapidly after initial learning, followed by a slower rate of decline.

<AsyncImage query="Ebbinghaus forgetting curve graph retention percentage time since learning educational psychology" aspectRatio="16:9" width="100%" />

The forgetting curve illustrates that memory retention may decrease substantially soon after learning if information is not reviewed.

The exact shape and rate vary depending on the material, learning method and individual.

## 10. Factors Affecting Memory

**Attention:** Information that receives attention is more likely to be encoded.

**Understanding:** Meaningful information is often easier to retain.

**Emotion:** Emotional experiences can influence memory strength and retrieval.

**Sleep:** Sleep supports memory consolidation.

**Stress:** Moderate and intense stress can affect memory differently depending on the situation.

**Practice:** Repeated retrieval and spaced review can improve retention.

## 11. Techniques for Improving Memory

### 11.1 Spaced Repetition

Review information at increasing intervals rather than concentrating all practice into one session.

### 11.2 Active Recall

Attempt to retrieve information from memory without looking at the answer.

### 11.3 Mnemonics

Mnemonics use associations, patterns or structured cues to aid memory.

### 11.4 Mind Maps

Mind maps organise concepts visually and show relationships between ideas.

### 11.5 Interleaving

Interleaving involves practising different but related topics within a study session.

### 11.6 Sleep and Rest

Adequate sleep supports learning and memory consolidation.

## 12. Summary

- Memory involves encoding, storage and retrieval.
- Sensory, short-term and long-term memory are major components of traditional memory models.
- Working memory temporarily maintains and manipulates information.
- Explicit memory includes episodic and semantic memory.
- Implicit memory includes procedural memory, priming and conditioning.
- Recall, recognition and relearning are different retrieval processes.
- Forgetting may involve decay, interference, retrieval failure or encoding failure.
- Proactive interference involves older information affecting newer learning.
- Retroactive interference involves newer information affecting older memories.
- Spaced repetition and active recall are useful memory strategies.
