A computer system consists of physical components called hardware and programs called software. Both work together to perform computational tasks.

## 1. Computer Hardware

Hardware refers to the physical components of a computer that can be seen and touched.

Major hardware categories include:

**Input devices:** Used to enter data and instructions.

Examples:
- Keyboard.
- Mouse.
- Scanner.
- Microphone.
- Webcam.
- Touchscreen.

**Processing devices:** Execute instructions and process data.

Examples:
- Central Processing Unit (CPU).
- Graphics Processing Unit (GPU).

**Output devices:** Present processed information.

Examples:
- Monitor.
- Printer.
- Speakers.
- Projector.

**Storage devices:** Store information and programs.

Examples:
- Hard Disk Drive (HDD).
- Solid State Drive (SSD).
- USB flash drive.
- Memory cards.

## 2. Computer Software

Software is a collection of programs and instructions that control computer operations.

Software is broadly divided into two categories.

### System Software

System software manages computer hardware and provides an environment for applications.

Examples:

- Operating systems.
- Device drivers.
- Language translators.
- System utilities.

### Application Software

Application software performs tasks for users.

Examples:

- Word processors.
- Web browsers.
- Spreadsheet applications.
- Media players.
- Image editing software.

## 3. Operating Systems

An operating system (OS) is system software that manages hardware resources and provides services to application programs.

Major functions include:

1. Process management.
2. Memory management.
3. File management.
4. Device management.
5. Security and access control.
6. User interface management.

Examples include Windows, Linux, macOS, Android and iOS.

## 4. Firmware

Firmware is software stored in non-volatile memory that provides low-level control of hardware devices.

Examples include:

- BIOS or UEFI firmware.
- Embedded device firmware.
- Router firmware.

Firmware is generally designed for a specific hardware device or function.

## 5. Hardware and Software Relationship

Hardware cannot perform useful general-purpose computing without instructions.

Software requires hardware to execute its instructions.

For example, when a user opens a web browser:

1. The operating system loads the browser program.
2. The CPU executes its instructions.
3. RAM stores active program data.
4. The display system presents the browser interface.
5. Input devices allow the user to interact with it.

## 6. Open-Source and Proprietary Software

| Open-source software | Proprietary software |
|---|---|
| Source code is available under an open-source licence | Source code is generally controlled by its owner |
| Users may modify and redistribute it under licence terms | Modification and redistribution are restricted by licence terms |
| Examples include Linux and PostgreSQL | Examples include Microsoft Windows and many commercial applications |

Open-source does not necessarily mean that software is free of cost.

## 7. Basic Characteristics of Computers

- Speed: Executes operations rapidly.
- Accuracy: Produces accurate results when instructions and input data are correct.
- Storage: Stores large amounts of information.
- Automation: Executes programmed tasks automatically.
- Consistency: Repeats operations without fatigue.
- Versatility: Performs different types of tasks.

Computers do not independently guarantee correct results. Incorrect input or instructions can produce incorrect output.

## Common Exam Traps

- Hardware refers to physical components.
- Software refers to programs and instructions.
- An operating system is system software.
- A web browser is application software.
- Firmware is stored in non-volatile memory.
- RAM is primary memory, not permanent storage.
- Open-source software is not automatically free of charge.
