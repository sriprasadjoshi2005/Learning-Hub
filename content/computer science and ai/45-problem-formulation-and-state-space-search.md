Artificial Intelligence frequently involves finding a sequence of actions that transforms an initial situation into a desired goal.

Before selecting a search algorithm, an AI system must represent the problem in a structured form.

Problem formulation and state-space representation provide the foundation for search, planning, and problem-solving agents.

## 1. Meaning of Problem Solving in AI

Problem-solving in AI involves identifying a suitable sequence of actions that leads from an initial state to a goal state.

Examples include:
- Finding a route between two cities.
- Solving a maze.
- Completing a puzzle.
- Planning a sequence of robotic movements.
- Finding a winning sequence in a game.

An AI problem-solving agent generally searches for a solution using a representation of possible states and actions.

## 2. Components of Problem Formulation

A well-defined AI problem contains five major components.

**Initial State:** The starting condition of the problem.

**Actions:** The operations available to the agent.

**Transition Model:** Describes the state resulting from performing an action.

**Goal Test:** Determines whether a state satisfies the objective.

**Path Cost:** Measures the total cost of a sequence of actions.

Example: Route Finding

Suppose an agent must travel from City A to City D.

- Initial state: City A.
- Actions: Travel along available roads.
- Transition model: Moving along a road reaches another connected city.
- Goal test: Check whether the agent has reached City D.
- Path cost: Total distance or travel cost.

## 3. State-Space Representation

A state space is the collection of all states that can be reached or considered while solving a problem.

It can be represented as a graph.

A graph consists of:
- Nodes representing states.
- Edges representing actions or transitions.

Example:

A simple state-space graph may contain:

A → B → D

A → C → D

The agent starts at A and attempts to reach D.

Possible paths include:
- A → B → D.
- A → C → D.

The search algorithm determines which path should be explored or selected.

## 4. State, Node, and Search Tree

These terms are related but different.

**State:** A description of a particular situation in the problem.

**Node:** A search structure containing information about a state, its parent, the action used to reach it, and other search details.

**Search Tree:** A tree generated by expanding nodes during search.

The same state may appear in multiple search-tree nodes if it can be reached through different paths.

## 5. State-Space Search

State-space search is the process of exploring possible states to find a solution.

A general search process involves:

1. Represent the problem.
2. Insert the initial state into the search structure.
3. Select a node for exploration.
4. Check whether the selected state satisfies the goal.
5. Expand the node by generating successor states.
6. Continue until a solution is found or no states remain.

The exact order of exploration depends on the search algorithm.

## 6. Search Tree Components

A search tree contains several important elements.

**Root Node:** Represents the initial state.

**Parent Node:** A node from which another node is generated.

**Child Node:** A node generated by expanding a parent.

**Leaf Node:** A node that has not been expanded.

**Depth:** The number of edges from the root to a node.

**Branching Factor:** The number of successors generated by a node, often represented by b.

Example:

If the initial state A produces B and C, then:
- A is the root.
- B and C are children of A.
- A has a branching factor of 2.

## 7. Solution and Optimal Solution

A solution is a sequence of actions that transforms the initial state into a goal state.

An optimal solution is a solution with the minimum path cost among all valid solutions.

Example:

Consider two possible routes:

- Route 1: A → B → D, total cost 10.
- Route 2: A → C → D, total cost 7.

If the objective is to minimize path cost, Route 2 is optimal.

A search algorithm may find a valid solution without necessarily finding the optimal one.

## 8. Search Strategy Evaluation

Search algorithms are commonly evaluated using four properties.

**Completeness:** Whether the algorithm is guaranteed to find a solution if one exists, under the relevant assumptions.

**Optimality:** Whether the algorithm is guaranteed to find the least-cost solution.

**Time Complexity:** How much computational work is required.

**Space Complexity:** How much memory is required.

These properties help determine whether an algorithm is suitable for a particular problem.

## 9. Search Complexity Notation

Search algorithms are often analyzed using:

- b: Branching factor.
- d: Depth of the shallowest goal.
- m: Maximum depth of the search tree.

A tree with branching factor b and depth d may contain a number of nodes proportional to:

1 + b + b² + ... + b^d

For b greater than 1, this is proportional to:

O(b^d)

The actual complexity depends on the search algorithm and the structure of the problem.

## 10. Repeated States and Cycles

Some state spaces contain cycles.

Example:

A → B → C → A

Without appropriate checks, a search algorithm may repeatedly explore the same states.

Repeated-state detection can prevent unnecessary exploration.

A common approach is to maintain an explored set containing states that have already been visited.

This is particularly important in graphs and environments with many alternative paths.

## 11. Applications of State-Space Search

State-space search is used in:
- Navigation and route planning.
- Puzzle solving.
- Automated planning.
- Game playing.
- Robot movement.
- Scheduling.
- Theorem proving.
- Configuration and optimization problems.

## Common Exam Traps

- A state represents a situation; a node is a structure used by the search algorithm.
- The initial state is the root of the search tree.
- The goal test determines whether the objective has been reached.
- Path cost measures the cost of a sequence of actions.
- A solution is not necessarily optimal.
- Completeness and optimality are different properties.
- Repeated-state detection helps prevent unnecessary cycles.
