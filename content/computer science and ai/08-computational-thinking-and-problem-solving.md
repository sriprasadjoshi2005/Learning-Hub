Computational thinking is a structured approach to solving problems using concepts and techniques from computer science. It helps transform complex problems into manageable steps that can be understood and implemented computationally.

## 1. Meaning of Computational Thinking

Computational thinking involves analysing problems and developing systematic solutions that can be executed by humans or computers.

It is not limited to programming. It is a general problem-solving approach.

## 2. Four Major Components

### Decomposition

Decomposition means breaking a complex problem into smaller, manageable parts.

Example:

An online shopping system can be divided into:

- User registration.
- Product browsing.
- Shopping cart.
- Payment processing.
- Order tracking.

Each component can be designed and tested separately.

### Pattern Recognition

Pattern recognition involves identifying similarities, repeated structures or trends in problems.

Example:

A program that calculates the sum of several numbers repeatedly performs addition. Recognising this pattern helps identify the need for iteration.

### Abstraction

Abstraction means focusing on important information while ignoring unnecessary details.

Example:

A map displays roads, locations and distances without showing every physical detail of the environment.

### Algorithm Design

Algorithm design involves creating a clear sequence of steps to solve a problem.

Example:

To find the larger of two numbers:

1. Read two numbers.
2. Compare them.
3. Display the greater number.
4. If they are equal, display an equality message.

## 3. Problem-Solving Process

A systematic computational problem-solving process includes:

1. Problem definition.
2. Requirement identification.
3. Problem decomposition.
4. Data identification.
5. Algorithm development.
6. Implementation.
7. Testing.
8. Evaluation and improvement.

## 4. Input, Process and Output

Many computational problems can be understood through the IPO model.

**Input:** Information supplied to a system.

**Process:** Operations performed on the input.

**Output:** Information produced by the system.

Example: Calculating the average of three numbers.

Input:
Three numerical values.

Process:
Add the values and divide the total by three.

Output:
The calculated average.

## 5. Logical Thinking

Logical thinking helps determine whether conditions and conclusions are valid.

Important logical operations include:

- AND: True when both conditions are true.
- OR: True when at least one condition is true.
- NOT: Reverses a Boolean value.

These operations are important in programming decisions.

## 6. Efficiency and Correctness

A good solution should satisfy two important requirements.

**Correctness:** The solution produces the expected result for valid inputs.

**Efficiency:** The solution uses reasonable computational resources, including time and memory.

A solution that produces correct results but takes excessive time may not be suitable for large problems.

## 7. Example: Finding the Largest of Three Numbers

Problem: Identify the largest among A, B and C.

Algorithm:

1. Read A, B and C.
2. Assume A is the largest.
3. Compare B with the current largest.
4. Update the largest if B is greater.
5. Compare C with the current largest.
6. Update the largest if C is greater.
7. Display the largest value.

This example demonstrates decomposition, comparison and algorithm design.

## Common Exam Traps

- Decomposition means dividing a problem into smaller parts.
- Pattern recognition identifies similarities and repetitions.
- Abstraction removes unnecessary detail.
- Algorithm design creates systematic solution steps.
- Computational thinking is broader than coding.
- Correctness and efficiency are different properties.
