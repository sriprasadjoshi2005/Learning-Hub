# Mathematics — 50-lesson learning library

This folder contains 50 standalone Markdown (`.md`) lessons, progressing from arithmetic foundations to mixed university-entrance-exam preparation.

## Learning route

| Stage | Lessons | Main areas |
|---|---:|---|
| Foundations | 01–10 | Arithmetic, number systems, sets, algebra, equations, polynomials and quadratics |
| Core algebra | 11–20 | Functions, sequences, binomial theorem, counting, complex numbers, matrices and probability |
| Trigonometry and geometry | 21–30 | Triangle geometry, trigonometry, coordinate geometry, circles and conics |
| Calculus | 31–42 | Limits, continuity, differentiation, applications, integration, area and differential equations |
| Exam preparation | 43–50 | Vectors, 3D geometry, statistics, logic, number theory and mixed revision |

## Format

Every lesson uses YAML-style front matter (`title`, `level`, `lesson`, `subject`) and Markdown headings. Lessons include learning objectives, core concepts, formulae, worked examples, common mistakes, an exam approach, three MCQs with marked answers and explanations, and a revision checklist.

## Suggested use

1. Complete lessons in order; the early lessons are prerequisites for later topics.
2. Work through each example on paper before reading its solution.
3. Attempt the quiz without looking at the marked answers.
4. Keep an error log and revisit weak topics.
5. Use the final lessons as a bridge to timed board/state-entrance/JEE Main practice.

## Scope note

This is a structured learning resource and a foundation-to-entrance preparation pathway, not an official syllabus or a substitute for the current exam information bulletin. Match final chapter coverage and question patterns to the latest syllabus of the examination you intend to take.
