# Lesson 39: Definite Integrals and Fundamental Theorem

## Learning objective

Evaluate definite integrals, interpret signed area and use symmetry and substitution properties.

## Core concepts

- The definite integral ∫_a^b f(x)dx is a limit of signed Riemann sums. It represents net signed area, not always total geometric area.
- If F'=f, the fundamental theorem gives ∫_a^b f(x)dx=F(b)−F(a). No arbitrary constant is needed in the final value.
- Reversing limits changes the sign: ∫_a^b f=−∫_b^a f. Equal limits give zero.
- If f is even, ∫_−a^a f(x)dx=2∫_0^a f(x)dx. If f is odd, the symmetric integral is zero.
- Substitution changes both the integrand and the limits when evaluating a definite integral.

## Essential formulae and results

If F'=f, ∫_a^b f(x)dx=F(b)−F(a).

## Worked examples

**Example 1.** ∫_0^2 3x² dx=[x³]_0^2=8.
**Example 2.** Since x³ is odd, ∫_−2^2 x³ dx=0.

## Common mistakes to avoid

- Do not take absolute value of every definite integral automatically; the integral is signed.
- When reversing limits, change the sign.
- For an even or odd shortcut, the interval must be symmetric about zero.

## Quick quiz

**1. ∫_0^1 2x dx equals:**
- [ ] 0
- [x] 1
- [ ] 2
- [ ] 4
> **Explanation:** Antiderivative is x²; evaluate 1−0=1.

**2. For an odd function f, ∫_−a^a f(x)dx is:**
- [ ] 2∫_0^a f
- [x] 0
- [ ] a
- [ ] Always positive
> **Explanation:** Odd symmetry cancels the two halves.

**3. ∫_a^b f(x)dx equals:**
- [ ] ∫_b^a f
- [x] −∫_b^a f
- [ ] 0
- [ ] |∫_b^a f|
> **Explanation:** Interchanging limits reverses orientation.
