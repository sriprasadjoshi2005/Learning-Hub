# Lesson 12: Graphs, Transformations and Inverse Functions

## Learning objective

Read function graphs, understand shifts and reflections, and identify when an inverse function exists.

## Core concepts

- The graph y=f(x) consists of points (x,f(x)). A vertical line intersects a function graph at most once.
- y=f(x)+k shifts the graph vertically by k; y=f(x−h) shifts it right by h. y=−f(x) reflects across the x-axis; y=f(−x) reflects across the y-axis.
- A function is one-one (injective) if distinct inputs give distinct outputs. The horizontal line test checks one-one behaviour on a graph.
- An inverse f⁻¹ reverses the mapping: f⁻¹(f(x))=x on the appropriate domain. To find it, write y=f(x), interchange x and y, then solve for y.
- A function may need its domain restricted before it has an inverse. The inverse graph is the reflection of the original graph in y=x.

## Essential formulae and results

Inverse: interchange x,y in y=f(x), then solve for y.

## Worked examples

**Example 1.** For f(x)=3x−2, set y=3x−2, swap: x=3y−2, so f⁻¹(x)=(x+2)/3.
**Example 2.** The graph y=(x−2)² is y=x² shifted two units to the right.

## Common mistakes to avoid

- f⁻¹(x) does not mean 1/f(x).
- A vertical shift changes output values, not the domain.
- The inverse domain equals the original range, and inverse range equals original domain.

## Quick quiz

**1. The graph of y=f(x)+3 is shifted:**
- [ ] 3 units left
- [ ] 3 units right
- [x] 3 units up
- [ ] 3 units down
> **Explanation:** Adding 3 outside the function shifts it upward.

**2. The inverse of f(x)=2x+4 is:**
- [ ] (x+4)/2
- [x] (x−4)/2
- [ ] 2x−4
- [ ] 4−2x
> **Explanation:** Swap x and y and solve x=2y+4.

**3. The horizontal line test checks whether a function is:**
- [ ] Continuous
- [x] One-one
- [ ] Even
- [ ] Periodic
> **Explanation:** A horizontal line meeting the graph more than once shows repeated outputs.
