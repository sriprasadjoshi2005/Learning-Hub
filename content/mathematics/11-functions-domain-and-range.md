# Lesson 11: Functions, Domain and Range

## Learning objective

Understand functions as input-output rules and learn to determine domain, range and common function types.

## Core concepts

- A function f from A to B assigns exactly one output in B to each input in A. One input cannot have two different outputs.
- The domain is the set of allowed inputs; the codomain is the declared target set; the range is the set of outputs actually attained.
- For f(x)=1/(x−2), x=2 is excluded from the domain. For f(x)=√(x−1), real inputs require x≥1.
- A function is even if f(−x)=f(x), and odd if f(−x)=−f(x), wherever defined. Even graphs are symmetric about the y-axis; odd graphs have origin symmetry.
- Composition is (f∘g)(x)=f(g(x)). It is defined only where g(x) lies in the domain of f.

## Essential formulae and results

(f∘g)(x)=f(g(x)); check domain restrictions.

## Worked examples

**Example 1.** If f(x)=2x+1, then f(3)=7. If g(x)=x², then (f∘g)(2)=f(4)=9.
**Example 2.** For f(x)=√(9−x²), require 9−x²≥0, so −3≤x≤3.

## Common mistakes to avoid

- The range need not equal the codomain.
- Check denominators and even-root radicands when finding a real domain.
- Composition order matters: f∘g is generally not g∘f.

## Quick quiz

**1. The domain of f(x)=1/(x−5) is:**
- [ ] All real numbers
- [ ] x>5
- [x] x≠5
- [ ] x≥5
> **Explanation:** The denominator cannot be zero.

**2. If f(x)=x²+1, f(−2) is:**
- [ ] −3
- [ ] 3
- [ ] 4
- [x] 5
> **Explanation:** (−2)²+1=5.

**3. A function satisfying f(−x)=f(x) is:**
- [ ] Odd
- [x] Even
- [ ] One-one
- [ ] Constant
> **Explanation:** This is the definition of an even function.
