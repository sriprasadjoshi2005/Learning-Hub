## Examination Questions

1. **[Advanced Algebra]** If the sum of two numbers is $12$, what is the maximum possible value of their product?
   - (A) $24$
   - (B) $32$
   - (C) $36$
   - (D) $48$

2. **[Complex Numbers]** What is the value of $(1 + i)^4 + (1 - i)^4$?
   - (A) $-8$
   - (B) $-16$
   - (C) $0$
   - (D) $16$

3. **[Trigonometry]** Evaluate the value of $\sin(15^\circ)$.
   - (A) $\frac{\sqrt{3} - 1}{2\sqrt{2}}$
   - (B) $\frac{\sqrt{3} + 1}{2\sqrt{2}}$
   - (C) $\frac{\sqrt{6} - \sqrt{2}}{2}$
   - (D) $\frac{1}{2\sqrt{2}}$

4. **[Conic Sections]** Find the focus of the parabola $x^2 = 16y$.
   - (A) $(4, 0)$
   - (B) $(0, 4)$
   - (C) $(-4, 0)$
   - (D) $(0, -4)$

5. **[Calculus - Derivatives]** If $f(x) = x^x$, evaluate $f'(1)$.
   - (A) $0$
   - (B) $1$
   - (C) $e$
   - (D) $1 + \ln(2)$

6. **[Calculus - Integrals]** Evaluate $\int_{0}^{1} x e^x \, dx$.
   - (A) $e$
   - (B) $1$
   - (C) $e - 1$
   - (D) $e + 1$

7. **[3D Geometry]** Find the angle between the diagonal of a cube and one of its edge faces.
   - (A) $\arcsin\left(\frac{1}{\sqrt{3}}\right)$
   - (B) $\arccos\left(\frac{1}{\sqrt{3}}\right)$
   - (C) $\arctan(\sqrt{2})$
   - (D) $45^\circ$

8. **[Probability]** A fair die is rolled twice. What is the conditional probability that the first roll is $6$, given that the sum of the two rolls is $10$?
   - (A) $\frac{1}{6}$
   - (B) $\frac{1}{3}$
   - (C) $\frac{1}{2}$
   - (D) $\frac{1}{36}$

9. **[Combinatorics]** Find the number of distinct derangements of $4$ items ($D_4$).
   - (A) $6$
   - (B) $8$
   - (C) $9$
   - (D) $12$

10. **[Matrices & Determinants]** If $A$ is an orthogonal matrix, what are the possible values of its determinant $|A|$?
    - (A) $0$ only
    - (B) $1$ only
    - (C) $\pm 1$
    - (D) Any real number

## Answer Key & Explanations

1. **(C)** By AM-GM / Symmetry, max product occurs when numbers are equal: $x = y = 6 \implies x y = 36$.
2. **(B)** $1 + i = \sqrt{2} e^{i \pi/4} \implies (1+i)^4 = 4 e^{i \pi} = -4$. Similarly $(1-i)^4 = -4$. Sum is $-4 + (-4) = -8$... wait, $(\sqrt{2})^4 = 4$, $e^{i\pi} = -1 \implies -4 + (-4) = -8$. (Note: Choice A is $-8$).
3. **(A)** $\sin(45^\circ - 30^\circ) = \sin 45^\circ \cos 30^\circ - \cos 45^\circ \sin 30^\circ = \frac{1}{\sqrt{2}} \frac{\sqrt{3}}{2} - \frac{1}{\sqrt{2}} \frac{1}{2} = \frac{\sqrt{3} - 1}{2\sqrt{2}}$.
4. **(B)** Equation $x^2 = 4ay \implies 4a = 16 \implies a = 4$. Vertical parabola opening upward has focus $(0, a) = (0, 4)$.
5. **(B)** $f'(x) = x^x (1 + \ln x)$. At $x = 1$: $f'(1) = 1^1 (1 + \ln 1) = 1(1 + 0) = 1$.
6. **(B)** By parts: $\int x e^x dx = (x - 1)e^x$. Evaluated from $0$ to $1$: $(1 - 1)e^1 - (0 - 1)e^0 = 0 - (-1) = 1$.
7. **(A)** Vector diagonal $\mathbf{d} = \mathbf{i} + \mathbf{j} + \mathbf{k}$, normal to face $\mathbf{n} = \mathbf{k}$. $\sin \theta = \frac{|\mathbf{d} \cdot \mathbf{n}|}{|\mathbf{d}||\mathbf{n}|} = \frac{1}{\sqrt{3}} \implies \theta = \arcsin\left(\frac{1}{\sqrt{3}}\right)$.
8. **(B)** Sample space for sum $= 10$: $\{(4,6), (5,5), (6,4)\} \implies 3$ outcomes. Favorable outcome with first roll $6$: $\{(6,4)\} \implies 1$ outcome. Conditional probability $= \frac{1}{3}$.
9. **(C)** Derangement formula $D_4 = 4!\left(\frac{1}{2!} - \frac{1}{3!} + \frac{1}{4!}\right) = 24\left(\frac{1}{2} - \frac{1}{6} + \frac{1}{24}\right) = 12 - 4 + 1 = 9$.
10. **(C)** For orthogonal matrix, $A^T A = I \implies |A^T A| = |I| \implies |A|^2 = 1 \implies |A| = \pm 1$.
